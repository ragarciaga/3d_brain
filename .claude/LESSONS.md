# Lessons

Project gotchas, written as instructions to a future agent. One entry per real incident,
1 to 3 lines, dated, newest last. Only the orchestrator (main session) appends here.
Planner and implementer prompts include the entries relevant to their task.

Format:
- YYYY-MM-DD: <instruction>. Why: <what went wrong once>.

- 2026-10-13: For an invariant test ("nothing moves", "nothing changes"), start from a state where a violation would be visible (several fragmentable pieces visible, non-trivial base) and assert every field that could move. Why: T2's R2.5 test passed by construction with one visible piece and explosion 0, and cost a kickback.
- 2026-10-13: Verifier and auditor cannot run `node scripts/...` or `npm run check:modelo` with arguments (guard); for script tasks the orchestrator runs the CLI exit-code checks itself in the mechanical check and quotes them in the PR. Why: T3's integration criterion was only observable in-process by the agents.
- 2026-10-13: Before building tasks in parallel (spec tasks or standalone rb:task issues), compare the Affected files of their plans (and shared areas: same component, same i18n block, same CSS block); any overlap means sequential, one task merged before the next starts. Only tasks with disjoint files run in parallel. Why: #58, #62 and #63 were built at once, all touched PanelRevision.tsx, and each merge forced conflict resolution plus a new verifier and auditor round on the others (editor rule).
- 2026-10-14: In Playwright, to assert something is absent during a transient state (a request in flight), read once (`expect(await loc.count()).toBe(0)`), never `toHaveCount(0)`, and hold the request with a promise in the route handler (`retenerAutorizar`, like `retenerLeer`) so the state lasts. Why: in T10 `toHaveCount(0)` retried until the request timed out and the state reverted, so the mutant survived and cost a kickback.
- 2026-10-14: `getByRole('button')` finds nothing inside a closed `<details>`; open its `summary` first. Why: T10's first VAG01 failed with "element(s) not found" although the entry was in `resto`.
- 2026-10-14: For self-mutation, mutate production code (or a shared helper such as `ALIAS_VALIDO`), never a test predicate: auto mode denies editing a test's guard as "Security Test Removal". Why: T11's mutation of `revisorPublico` in the test was denied mid-run.
- 2026-10-14: With `react-hooks/immutability`, declare a function before any `const` closure that calls it, even if the call happens later. Why: T9's `enviarTodo` had to move above `estadoUI`.
- 2026-10-15: `MeshBVH` reorders `geometry.index` in place, and the GLB shares index buffers between twin meshes (dedup), so building one tree broke its twin's; build trees with `construirBvh` (copies the index). Why: 01-T7, two brainstem nuclei had no outline and 24 meshes had broken touch.
- 2026-10-15: An e2e assertion `> 0` on a measured duration does not catch a misplaced mark when the remaining span has its own cost; measure the real and the mutated value and put the threshold between them. Why: #85, the touch-index mark moved before the BVH loop still gave 2 to 19 ms.
- 2026-10-15: Stop only the processes you started, by PID or port; never `pkill -f vite` or `pkill -f playwright` (other agents run them in other worktrees), and never run two Playwright processes in one worktree (they share test-results). Why: 03-T13's implementer killed its own run and broke traces.
- 2026-10-15: With react-router, `toHaveURL` passes before the ficha changes (location updates inside a React transition); before clicking a control that also exists in the previous ficha (same `data-campo`), wait for `#ficha-titulo` to show the new name. Why: 01-T8's CI clicked "Corregir" on the old ficha and unpressed it.
- 2026-10-16: Blender runs in the cloud: `pip install bpy==5.2.2 pyyaml==6.0.2` in a Python 3.13 venv works, and the Z-Anatomy zip downloads from `raw.githubusercontent.com` (the proxy blocks `github.com/.../raw/`); `descargar.py` verifies the SHA-256. Try this before escalating a pipeline check as `rb:needs-local`, and run pipeline scripts as the editor does (`python pipeline/<script>.py`), not only through a test that imports `bpy` first. Why: #49 waited two days for the editor's laptop, and `import bmesh` before `import bpy` broke `extraer.py` unnoticed.
- 2026-10-16: In this cloud environment Playwright needs `PW_CHROMIUM_PATH=/opt/pw-browsers/chromium` (the pinned version's headless shell is not installed); pass it to every agent that runs e2e or a browser audit. Why: the browser probe failed with "Executable doesn't exist" until the variable was set.
- 2026-10-16: Do not edit files in a worktree while a Playwright run uses that worktree's dev server: Vite reloads the page and unrelated tests fail. Why: i162's AUT01 failed once from a reload during mutation edits.
- 2026-10-16: A test that a CLI never leaks a secret through a JSON parse error needs a fixture whose V8 message quotes the input ("Unexpected token" with the secret within ~10 characters, e.g. `{"QQSECRETOX":D07}`), plus an assertion that `JSON.parse` of the fixture throws a message containing the secret; a trailing comma or a missing `,` gives a message without the input. Why: #166's padrón test would not have caught a regression that printed `e.message`.
- 2026-10-16: With cutting planes active, a click at the canvas center can hit the relleno mesh (`RellenoDePieza`, which has its own raycast) instead of the piece: a mutation meant to break touch must go in the shared `raycastCorte`, not only in `Pieza`'s raycast. Why: #178's planned mutation survived until it moved to `raycastCorte`.
- 2026-10-16: The cut-mode cost on PowerVR GPUs comes from `discard` in every material with `clippingPlanes`, not from vertices: SwiftShader shows no difference, so judge cut performance with draw-call and triangle counts plus the overdraw model, and confirm on the device. Why: #177 (3 fps on the Tecno with cuts, 25 without).
- 2026-10-16: An e2e test that opens a second page in the same context must abort `**/modelos/atlas.glb` when it does not need the model: two pages rendering the full model with software WebGL starve the CI runner, and the second page stops handling keys and `storage` events for minutes. Why: #149 P1 failed twice in CI and never locally.
- 2026-10-16: Never write a value back to localStorage on every effect run when it came from localStorage itself: Chromium syncs localStorage between tabs asynchronously, so a stale read can resurrect a value another tab just deleted. Write only from the real source (the `?r=` link). Why: #149, the reviewer code reappeared after "Borrar" in another tab.
- 2026-10-17: In E2E, "camera still" must check `__camara.desfase() < 1e-4` (and `pedidosAplicados` rising after a camera request), not two equal `__camara.leer()` reads: `leer` returns the CameraControls destination, which stops changing before the real camera arrives when frames are starved (CPU throttling, touch index building); a point projected with the still-moving camera is stale by the time the click raycasts, so it misses a small target such as a 5 px marker sphere. Why: #201 (`cortes-marcadores` step 2 failed in CI twice; reproduced with CDP CPU throttling x4 in 2 of 8 runs, 0 of 10 with the fix).
